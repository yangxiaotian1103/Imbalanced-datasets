# Imbalanced-datasets
1. Synthetic 2D Dataset
A two-dimensional, two-class imbalanced dataset generated by the authors for visualizing classifier decision boundaries and the sampling behaviour of the proposed method.
Structure. Each sample is represented by its coordinates (x, y), with two classes — a majority class and a minority class — each following a Gaussian distribution. Class labels are encoded in a separate column.
Class distribution. In both the training and the test split, the majority class contains 3,000 samples and the minority class contains 300 samples, giving an imbalance ratio of 10:1.

2. CWRU Bearing Dataset (Processed Feature Set)
A pre-processed feature set derived from the public Case Western Reserve University (CWRU) bearing dataset (https://engineering.case.edu/bearingdatacenter). Only the derived feature vectors are deposited here; the original vibration signals remain available from the CWRU source under its own terms.
Source signals. Vibration signals collected under varying operating conditions (loads and motor speeds) and multiple fault types (inner-race, outer-race, and ball-element defects).
Task formulation. Imbalanced binary classification distinguishing normal operation (minority class) from faulty states (majority class).
Feature representation. Each sample is a 24-dimensional feature vector extracted from time-domain and frequency-domain signal characteristics.
Class distribution. 9,736 samples in total — 942 normal vs. 8,794 faulty, an imbalance ratio of approximately 1:9.3.
